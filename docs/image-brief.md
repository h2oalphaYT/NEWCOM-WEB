# Newcom website: image brief

One photo per menu item so no two items share a picture. Match the style of the images already supplied:
dark charcoal set, single product, deep red rim light and soft red bokeh, studio product shot, no text,
no brand logos, 4:3 landscape, at least 1024×768. Save as PNG or JPG with the file name in the first column
and send them over; they go into `frontend/public/media/cat/`.

Prompt template (paste the subject into it):

> Studio product photo of **[subject]** on a dark charcoal surface, deep red rim lighting, soft red bokeh in the background, cinematic, high detail, no text, no logos, 4:3
